# The Abacus Foundation

This is the public GitHub organization profile for [The Abacus Foundation](https://github.com/The-Abacus-Foundation).

The landing page people see at the organization is [`profile/README.md`](profile/README.md).

## What we publish

- [Accounting](https://accounting.theabacus.org) — local-first books for small businesses and nonprofits
- [PDF](https://pdf.theabacus.org) — on-device merge, split, compress, convert, and sign
- [Calculators](https://calculator.theabacus.org) — 58+ privacy-first calculators on the web
- [Abacus Calculators (iOS)](https://apps.apple.com/us/app/abacus-calculators-suite/id6756740335) — native iPhone, iPad, and Mac app
- [Projects](https://theabacusfoundation.org/projects) — client work such as [Fuel Price Tracker](https://theabacusfoundation.org/projects/fuel-price-tracker)
